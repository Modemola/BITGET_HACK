02

Before you trade the premium

That weekend premium is not free money.

Across 27 weekend blackouts, the gap between rToken and fair value closed almost entirely because the reference caught up once futures reopened — not because the token corrected. The token leg, the only one you can actually trade, contributes almost nothing. Fading it is a coin flip that loses to fees.
